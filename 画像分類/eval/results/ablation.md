# 劣化フィルタのアブレーション実験評価結果

学習データの劣化条件を変えた3モデルにおける、本物 reCAPTCHA 画像での精度(AP)比較結果。

| 学習条件 | 学習データ | 枚数/クラス | real_recaptcha AP | 参考: zero-shot AP (0.875) との差 |
|---|---|---:|---:|---:|
| A: clean | 原本のみ | 100 | 0.842 | -0.033 |
| B: 旧フィルタ | 原本＋夜＋雨 | 300 | 0.911 | +0.036 |
| C: 新フィルタ | 原本＋degraded1＋degraded2 | 300 | 0.896 | +0.021 |

> [!NOTE]
> 条件Aは学習枚数が100枚/クラスと少なく、B・C（300枚/クラス）との比較において「データ総枚数」の違いが含まれることに注意。

> [!WARNING]
> **事後訂正（2026-07-07）**：条件Cとして評価した `best_resnet18_bus.pth` は、実際には**6/25の旧フィルタ学習モデル**だった
> （新フィルタ再学習は別マシンで行われ、.pth は git 管理外のため未同期）。
> よって B と C はどちらも旧フィルタであり、「B ≈ C＝フィルタ種類の寄与は小さい」という当初の解釈は**無効**。
> 有効な知見は (1) 劣化つき水増しは clean のみより明確に効く（0.842 → 0.896〜0.911）、
> (2) 同一条件でも実行間で AP が ±0.015 程度ぶれる（B=0.911 vs C=0.896）、の2点。
> 正しいラベルの表は README §6「アブレーション」を参照。
